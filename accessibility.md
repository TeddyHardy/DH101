This site was built by Teddy Hardy for DH 101: Critical Making in the Age of AI at Denison University.

I have tried to make it accessible by:

- **Writing descriptive alt text for every image** (Makes 2–8), describing what each image actually shows, not just its title. Complex images, like my network graph, have longer descriptions plus a text version of the data.
- **Checking color contrast** with the WebAIM Contrast Checker. My main text (#222 on #fafafa) has a 15.2:1 ratio, and my red accent color (#b3122a) has a 6.9:1 ratio on white, both above the WCAG AA minimum of 4.5:1. I darkened the theme's light gray text from #828282 (3.8:1, which failed) to #666666 (5.7:1).
- **Using descriptive link text**, such as "Explore the interactive version of my AI supply chain network on Kumu," instead of "click here."
- **Keeping headings in order** (page title, then section headings, then subsections) so screen readers can navigate each page.
- **Using a responsive theme** so pages work on phones as well as computers.
- **Not relying on color alone.** My network labels every node by name and uses dashed and dotted line styles, not just colors, to show relationships. It also includes a written legend and a text table of every connection.

**Known limits:** some AI-generated images contain text (like comic captions) that is only partly described in alt text, and the interactive Kumu network may be harder to use with a screen reader, which is why I included a text table of its connections.

If you encounter barriers, please contact me at hardy_t2@denison.edu.
